## إصداران — اختر ملفاً واحداً

| الملف | لمن | الصياغة العربية | ملف التشغيل | البيانات النموذجية |
|---|---|---|---|---|
| **`LRC_System.html`** | مدارس البنين (الافتراضي) | طلاب / معلمون | `START_LRC.bat` | `samples/` |
| **`LRC_System_F.html`** | مدارس البنات | طالبات / معلمات | `START_LRC_F.bat` | `samples_F/` |

الإصداران متطابقان في الميزات والشاشات وصيغة قاعدة البيانات — الفرق فقط في الصياغة العربية (الواجهة الإنجليزية واحدة). استخدم ملفاً واحداً لكل مدرسة؛ يظهر اسم الإصدار أسفل كل صفحة.

## ما هو البرنامج

`LRC_System.html` هو البرنامج كاملاً في **ملف HTML واحد** (حوالي 2.3 ميغابايت). يجمع بين نظام الإعارة السابق وأداة الجرد بالباركود. لا يحتاج إلى خادم ولا تثبيت ولا اتصال بالإنترنت — انقر على الملف نقراً مزدوجاً ليفتح في Chrome أو Edge.

## البدء السريع

1. نزّل هذا المستودع (زر **Code ▸ Download ZIP** الأخضر أو `git clone`) وفك الضغط في أي مكان على الجهاز — أو انسخ ملف HTML الخاص بإصدارك فقط.
2. شغّل **`START_LRC.bat`** (بنين) أو **`START_LRC_F.bat`** (بنات)، أو افتح ملف HTML مباشرة في Google Chrome / Microsoft Edge.
3. اضغط **اختيار مجلد** في الشريط الأزرق واختر مجلد **المستندات (Documents)**. بعدها تُحفظ قاعدة البيانات وجميع النسخ الاحتياطية هناك تلقائياً (انظر أدناه).
4. استورد قوائم الطلاب والكتب من ملفات CSV (صفحة استيراد/تصدير) — أو استعد ملف `lrc_library.db` من النسخة السابقة.

## الميزات

| المجال | التفاصيل |
|---|---|
| **الإعارة بالباركود** | الإعارة بالرقم العام للكتاب عبر قارئ الباركود، مع تجاهل الأصفار على اليسار (`00045` = `45`). |
| **تنبيهات لا منع** | إذا كان لدى الطالب كتب غير مرجعة يظهر تنبيه واضح، وإذا استعار أكثر من 3 كتب في اليوم يظهر تنبيه — ويُسمح بالإعارة في الحالتين. |
| **الإرجاع** | بمسح باركود الكتاب (إرجاع فوري مع إمكانية التراجع) أو بالبحث باسم الطالب وإرجاع المحدد أو الكل. |
| **المستفيدون** | إضافة وتعديل وحذف الطلاب والمعلمين يدوياً في أي وقت، أو الاستيراد من CSV. |
| **إعارات المعلمين** | سجل مستقل للمعلمين والفعاليات مع قائمة إعارات نشطة خاصة. |
| **التقارير** | بتحديد التاريخ من / إلى؛ للكل أو حسب الصف والشعبة أو حسب الطالب؛ مع التصدير CSV والطباعة. |
| **الجرد** | جرد سنوي بالباركود مع الكتب متعددة النسخ، والتالفة، والخارجة عن القائمة، ومتابعة التقدم والاستئناف، وتقارير وتصدير كاملة. |
| **البحث والتحليلات** | بحث شامل؛ اتجاهات شهرية، أكثر المستعيرين، أشهر العناوين، الإعارات حسب الصف، تحليل التأخير. |
| **ثنائي اللغة** | العربية (من اليمين لليسار، الافتراضي) والإنجليزية، بالتبديل من القائمة. |

## أين تُحفظ بياناتك

| الموقع | متى | ماذا |
|---|---|---|
| تخزين المتصفح (IndexedDB) | دائماً | نسخة من قاعدة البيانات SQLite تُحفظ بعد كل عملية. |
| `Documents\LRC_Library\lrc_library.db` | بعد اختيار المجلد | ملف قاعدة البيانات، يُعاد كتابته بعد كل عملية. |
| `Documents\LRC_Library\backups\lrc_backup_<التاريخ>_<السبب>.db` | تلقائياً | كل 50 عملية حفظ، ومرة يومياً عند أول تشغيل، وقبل أي استعادة أو إعادة تعيين، وعند الطلب. تُحذف النسخ القديمة تلقائياً (الافتراضي: الاحتفاظ بـ 40). |
| `Documents\LRC_Library\backups\csv_<التاريخ>\` | عند الطلب («نسخة كاملة») | الطلاب والكتب والمعلمون والإعارات وإعارات المعلمين والجرد بصيغة CSV. |

- عند التشغيل يقارن البرنامج نسخة المتصفح بملف المجلد؛ **الأحدث هو المعتمد** والأخرى تُحفظ كنسخة احتياطية.
- في التشغيلات اللاحقة قد يطلب المتصفح **إعادة الاتصال** بنقرة واحدة.
- بدون مجلد، تُنزَّل النسخ الاحتياطية التلقائية كملفات من المتصفح.
- جهاز واحد نشط لكل مجلد بيانات في الوقت نفسه. الإصداران يستخدمان نفس صيغة قاعدة البيانات، فالمجلد الذي أنشأه أحدهما يفتح في الآخر.

## استيراد ملفات CSV من Excel (النصوص العربية)

يحفظ Excel على ويندوز العربي ملفات *CSV (محدد بفواصل)* بترميز **Windows-1256**، وملفات *نص Unicode* بترميز **UTF-16 مع Tab**. صفحة الاستيراد:

- تكتشف الترميز (UTF-8، UTF-16، Windows-1256، ISO-8859-6) والفاصل (`,` أو `;` أو Tab) تلقائياً،
- تعرض **معاينة لأول 5 صفوف** للتأكد من صحة العربية قبل الاستيراد،
- تتيح تغيير الترميز يدوياً،
- ويمكنها **تحديث السجلات الموجودة** (فعّل الخيار) لإصلاح أسماء أو عناوين استُوردت مشوهة سابقاً.

الأعمدة المطلوبة: الطلاب `stNumber, stName, stClass, stSec` — الكتب `Gnumber, BookTitle` مع عمود اختياري `CNumber` (تكرار الرقم داخل الملف يعني نسخة مادية إضافية).

## أرقام التصنيف (CNumber) والفئات

يمكن أن يحمل كل كتاب رقم تصنيف ديوي في عمود اختياري اسمه **`CNumber`**. إذا لم يوجد العمود يُستورد الملف بشكل طبيعي بدون أي تنبيه. الصيغ المقبولة: `892.73` و`892,73` (فاصلة عشرية، داخل علامات اقتباس أو بدونها) و`892` فقط. الأرقام الثلاثة الأولى تحدد الفئة:

| النطاق | الفئة |
|---|---|
| 000-099 | المعارف العامة وتشمل علم الحاسبات، المعلومات والأعمال العامّة (Generalities) |
| 100-199 | الفلسفة وعلم النفس (Philosophy) |
| 200-299 | الديانات (Religions) |
| 300-399 | العلوم الاجتماعية (Social sciences) |
| 400-499 | اللّغات (Languages) |
| 500-599 | العلوم البحتة ويتضمّن الرياضيات (Pure sciences) |
| 600-699 | العلوم التطبيقية / التقانة (Applied sciences) |
| 700-799 | الفنون والاستجمام والديكور (Fine arts) |
| 800-899 | الآداب (Literatures) |
| 900-999 | التاريخ، الجغرافيا والتراجم / السيرة الذاتية (History, geography) |

أين تظهر الفئات: صفحة **التقارير** فيها مرشّح للتصنيف وتبويب «حسب التصنيف» (الإعارات، النسبة، العناوين المختلفة، غير المرجعة، المتأخرة لكل فئة)، و**التحليلات** فيها رسمان «الإعارات حسب التصنيف» و«المجموعة حسب التصنيف»، و**لوحة التحكم** تعرض أكثر التصنيفات إعارة، و**البحث** ولوحات المسح في الإعارة والجرد تعرض الرقم والفئة، وتصدير الجرد يتضمن عمود `CNumber`. إعادة استيراد قائمة الكتب بعد إضافة `CNumber` إليها تُكمل الأرقام للكتب الموجودة دون تغيير أي شيء آخر.

## المتصفحات المدعومة

يُنصح بـ Google Chrome أو Microsoft Edge (الإصدارات الحالية) لأنهما يدعمان الحفظ المباشر في مجلد المستندات. المتصفحات الأخرى تشغّل البرنامج لكنها تحتفظ بالبيانات في تخزين المتصفح فقط وتنزّل النسخ الاحتياطية كملفات.

## الأمان

- سياسة أمان المحتوى (CSP) مبنية على البصمات: لا يعمل إلا الكود المضمّن، ولا يوجد أي اتصال بالشبكة.
- كل المخرجات مُرمَّزة ضد XSS؛ كل الاستعلامات تستخدم معاملات مربوطة؛ تصدير CSV يحيّد حقن الصيغ.
- التحليل الثابت (Semgrep، 328 قاعدة) والاختبار الديناميكي (Playwright/Chromium، أكثر من 150 فحصاً آلياً لكل إصدار تشمل XSS وCSP وحقن SQL/CSV وسيناريوهات النسخ الاحتياطي) موثّقان في مجلد `security/` بالمشروع.
